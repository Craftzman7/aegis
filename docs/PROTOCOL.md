# Aegis Protocol Contract (source of truth for agent ⇄ server ⇄ dashboard)

All JSON. Timestamps RFC3339 UTC strings unless noted. IDs are UUIDv4 strings.
Base64 = standard base64 with padding. Ed25519 everywhere.

## 1. Keys
- **Server signing key**: Ed25519. Private key stored as Worker secret `SIGNING_KEY_JWK` (JWK JSON string, `{"kty":"OKP","crv":"Ed25519","d":..,"x":..}`). Public key (raw 32 bytes, base64) is returned at enrollment as `server_pubkey`; the agent pins it on disk and verifies every command/policy with it.
- **Agent key**: Ed25519 keypair generated by the agent on first enroll, stored at `/var/lib/aegis/agent.key` (0600). Raw 32-byte pubkey sent base64 at enrollment.

## 2. Agent → Server HTTP auth
Every request except `/v1/enroll` carries:
```
X-Aegis-Host: <host_id>
X-Aegis-Ts:   <unix seconds>
X-Aegis-Sig:  base64(ed25519_sign(agent_priv, canonical))
canonical = METHOD + "\n" + PATH + "\n" + TS + "\n" + hex(sha256(body))   // body = "" for GET
```
PATH is the URL path only (no query). Server rejects if |now − ts| > 300s or signature invalid → 401.

## 3. Endpoints (agent)
| Method | Path | Body | Response |
|---|---|---|---|
| POST | `/v1/enroll` | `{token, hostname, os, arch, kernel, agent_version, pubkey}` | `{host_id, server_pubkey, policy: SignedEnvelope}` |
| POST | `/v1/events` | `{anomalies: Anomaly[]}` (≤ 500 per batch) | `{accepted: n}` |
| POST | `/v1/heartbeat` | `{agent_version, policy_version, uptime_s, stats:{events_per_min, anomalies_per_min, rules_loaded, buffer_events}, rule_errors:[{rule_id, error}], ws_connected}` | `{policy_version}` (latest; agent fetches if newer) |
| GET | `/v1/policy` | — | `SignedEnvelope` (policy) |
| GET | `/v1/commands` | — | `{commands: SignedEnvelope[]}` (pending; poll fallback when WS down, every 15s) |
| POST | `/v1/results` | `CommandResult` | `{ok:true}` |
| GET | `/v1/ws` | — (auth headers, WebSocket upgrade) | WS stream of `ServerMessage` |

Enrollment tokens: one-time, created from console, stored hashed (sha256 hex) in D1 `enroll_tokens`, TTL.

## 4. Types
```ts
type Severity = "info"|"low"|"medium"|"high"|"critical";

interface Anomaly {
  id: string; ts: string;
  rule_id: string;                       // sigma rule id, or "native:<name>", "baseline:<metric>", "ioc:<type>"
  rule_source: "sigma"|"native"|"baseline"|"ioc"|"yara";
  rule_title: string;
  category: "auth"|"process"|"network"|"file"|"user"|"persistence"|"other";
  severity: Severity;
  fingerprint: string;                   // stable dedup key (sha256 hex of rule_id + key fields)
  summary: string;                       // one line, human readable
  attack_tags: string[];                 // e.g. ["attack.t1059.004","attack.execution"]
  falsepositives: string[];              // from sigma, may be []
  shadow: boolean;                       // true if from a shadow-mode rule (server logs only, no incident)
  evidence: Record<string, unknown>;     // normalized event(s) that triggered; ≤ 32KB JSON
}

interface SignedEnvelope { payload: string /* base64(JSON bytes) */; sig: string /* base64 sig over the raw JSON bytes */ }

// payload of a command envelope
interface Command {
  id: string; host_id: string;
  action: AgentAction; params: Record<string, unknown>;
  issued_at: string; expires_at: string;  // agent rejects expired or host_id mismatch; dedups by id
}

// payload of a policy envelope
interface Policy {
  host_id: string; version: number; issued_at: string;
  body: {
    log_level: "info"|"debug";
    thresholds: Record<string, number>;   // e.g. {"native:ssh_bruteforce.count": 10, "native:ssh_bruteforce.window_s": 60, "baseline.zscore": 4}
    watches: { kind: "path"|"process"|"port"; target: string }[];
    suppressions: { fingerprint: string; expires_at: string; reason: string }[];
    rules: { id: string; status: "active"|"shadow"|"disabled"; yaml: string }[];  // Sigma YAML
    iocs: { type: "ip"|"sha256"|"domain"; value: string }[];
    server_endpoints: string[];           // never block / always allowed under isolation
  };
}

interface CommandResult {
  command_id: string; status: "succeeded"|"failed"|"rejected";
  result?: Record<string, unknown>; error?: string; rollback_token?: string;
}

type ServerMessage =
  | { type: "command"; envelope: SignedEnvelope }
  | { type: "policy_updated"; version: number }   // agent then GETs /v1/policy
  | { type: "ping" };
```

## 5. Action vocabulary (fixed; nothing else is ever executed)
Server-side-only (become a new signed policy version, never sent as a command):
| action | params | tier |
|---|---|---|
| `adjust_threshold` | `{key, value}` (≤3× / ≥⅓ of current) | 0 |
| `add_watch` | `{kind, target}` | 0 |
| `suppress` | `{fingerprint, ttl_seconds ≤ 604800, reason}` (not allowed for severity high/critical rules) | 1 (reduces detection) |
| `propose_rule` | `{title, yaml}` → added as `shadow` | 0 |
| `promote_rule` | `{rule_id}` shadow→active | 1 (or auto by FP stats) |
| `disable_rule` | `{rule_id}` | 1 (reduces detection) |

Agent commands (sent as signed `Command`):
| action | params | tier | result |
|---|---|---|---|
| `collect_evidence` | `{kind: "process_tree"\|"open_files"\|"netconns"\|"file_hash"\|"log_excerpt"\|"user_info"\|"file_sample", target?: string}` | 0 | `{data}` |
| `test_rule` | `{yaml}` | 0 | `{matches, samples[]}` over local 24h ring buffer |
| `yara_scan` | `{path, rules?: string}` | 0 | `{matches[]}` (or `failed` if built without yara) |
| `raise_log_level` | `{ttl_seconds ≤ 86400}` | 0 | `{}` |
| `kill_process` | `{pid, start_time?}` | 1 | `{killed}` |
| `block_ip` | `{ip, ttl_seconds ≤ 604800}` | 1 | `{}` + rollback_token |
| `disable_user` | `{username}` (never root/uid 0 or the agent's own) | 1 | `{}` + rollback_token |
| `quarantine_file` | `{path}` | 1 | `{quarantine_path, sha256}` + rollback_token |
| `isolate_host` | `{ttl_seconds ≤ 86400}` (allow server_endpoints + loopback) | 1 | `{}` + rollback_token |
| `rollback` | `{rollback_token}` | 0 | `{}` |

## 6. Live feed (FleetDO → dashboard)
`GET /console/live` WebSocket. Messages: `{type, data, ts}` where
`type ∈ "anomaly"|"incident"|"ai_review"|"action"|"host"|"audit"|"policy"|"agent_turn"`, `data` = the D1 row (JSON columns parsed; for `agent_turn`, `content_json` is parsed into `content`).

## 7. Console API (dashboard; Cloudflare Access JWT, or `DEV_MODE=true` → user `dev@local`)
All under `/console/api`. Rows returned with `*_json` columns parsed into objects (key minus `_json`).
- `GET /me` → `{email}`
- `GET /overview` → `{hosts:{total,online,offline,isolated}, incidents_by_severity, pending_approvals, anomalies_24h_hourly:[{hour,count}], ai_actions_24h, autonomy}`
- `GET /hosts`, `GET /hosts/:id` → `{host, anomalies, incidents, actions, policy}`
- `POST /hosts/:id/autonomy` `{mode}`; `GET|POST /settings/autonomy` global `{mode: "autonomous"|"propose_only"|"paused"}`
- `GET /incidents?status=&severity=&host=`, `GET /incidents/:id` → `{incident, anomalies, reviews, actions, audit, turns: AgentTurn[]}` (turns ordered by `run_id`, `seq`)
- `POST /incidents/:id/verdict` `{verdict:"true_positive"|"false_positive", note}`
- `POST /incidents/:id/ask` `{question}` → `{answer}` (read-only)
- `GET /approvals` → pending tier-1 actions (with incident + host)
- `POST /actions/:id/approve` `{params?, ttl_seconds?}`; `POST /actions/:id/reject` `{reason}`; `POST /actions/:id/rollback`
- `POST /actions` `{host_id, action, params, incident_id?}` manual action (human, goes through gate bounds, tier ignored)
- `GET /audit?limit=&before=`
- `GET /rules`, `POST /rules` `{yaml, status}`, `POST /rules/:id/status` `{status}`, `POST /rules/lint` `{yaml}` → `{ok, errors[]}`, `POST /rules/:id/test` `{host_id}`
- `GET /coverage` → `{techniques:[{id, rules, hits_30d}]}`
- `GET /policies/:hostId` (history), `POST /policies/:hostId` `{body, reason}`
- `POST /enroll-tokens` `{ttl_hours}` → `{token, expires_at}` (shown once)
- `GET /export/incidents/:id.ocsf.json`, `GET /export/iocs.stix.json`, `POST /iocs/import` (STIX bundle or CSV `type,value`)
- `GET /evidence?key=` → R2 object JSON

## 8. Agentic investigation (agent loop)

Incident `status` also takes the value `"resolved"`: containment succeeded **and** the AI verified it with tools. It is not closed. A human confirms it with the existing `POST /incidents/:id/verdict {verdict: "true_positive"}`, which closes it as `closed_tp`. The AI never sets `closed_tp` itself.

Action rows gain `critic_json` (parsed into `critic`), set on tier-1 proposals that went through the second-opinion review:
```ts
interface CriticNotes { decision: "submit" | "revise"; concerns: string[]; missing_checks: string[]; round: number }
```

The investigator's transcript, one row per message:
```ts
interface AgentTurn {
  id: string; incident_id: string; run_id: string; seq: number; ts: string;
  role: "user" | "assistant" | "tool";
  tool_name: string | null;            // for role=tool: the tool that produced this result
  tool_call_id: string | null;
  content: {
    text?: string;                                                      // assistant prose / user message
    tool_calls?: { id: string; name: string; arguments: Record<string, unknown> }[];  // assistant
    result?: unknown;                                                   // tool result (already untrusted-wrapped server-side when sent to the model)
    error?: string;                                                     // tool error (bad args, gate rejection)
    action_id?: string;                                                 // tool calls that created an actions row
  };
}
```
